# Pranish (Nish) Pakwan

I'm Nish. I build AI tools, and my background is in analytics and business systems. Right now I'm working on HiredStack, a product to help people manage their job search.

## Selected work

### [Marketing Studio](https://github.com/nishpn01/marketing-studio)

I built Marketing Studio for HiredStack. I give it a rough idea and the sources I want it to use. One agent writes the draft, separate reviewers check the claims and the writing, and I approve the version I want to use.

### [Inbox Agent](https://github.com/nishpn01/inbox-agent)

An inbox triage tool that suggests labels and explains why each one fits. Corrections carry into the next run, and the person using it can approve changes to the labeling rules. The [demo](https://inbox-agent-tan.vercel.app) uses 49 fictional emails.

### [AI Document Intelligence](https://github.com/nishpn01/ai-document-intelligence)

During my Pfizer externship, I compared OCR and retrieval approaches for answering questions about PDFs. I checked answers against the source documents and investigated failures in retrieval and errors in the answer key.

### [Program Viability Assessment](https://github.com/nishpn01/program-viability-assessment)

I joined federal education and labor data in PostgreSQL, scored 1,254 possible online graduate programs for Vanderbilt, and narrowed the list to five. The [Tableau dashboard](https://public.tableau.com/app/profile/pranish.p7454/viz/OnlineProgramViabilityAssessment/Program_Overview_Dashboard2) shows the evidence behind the shortlist.
